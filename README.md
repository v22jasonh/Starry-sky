# 中国金融官方文件 Skill 包

入口文件：`SKILL.md`

当前版本：**v2.0**

用途：建立中国金融业务“全链条法律规范检索与效力分析”工作流。以民法典为民事实体法基础，以公司法、民诉执行、破产、仲裁为债权实现与主体责任基础，并向银行、保险、证券、基金、期货、信托、资管、反洗钱、税务会计、市场监管、数据与个人信息、刑事、行政监管、国资、外汇跨境、公安反诈、不动产及地方金融规则动态扩展。

核心原则：
1. 官方原文优先；
2. 法律/行政法规/司法解释优先于部门规范；
3. 历史机构映射；
4. 现行效力必须单独核验；
5. 新旧法按法律事实时间轴适用；
6. 征求意见稿、新闻稿、政策解读不得冒充现行规范；
7. 静态清单只规定“最低检索范围”，不得限制进一步检索。

文件：
- `SKILL.md`：主规则；
- `SOURCE_MATRIX.md`：官方来源优先级和专题来源；
- `LEGAL_COVERAGE_MATRIX.md`：全链条最低法律规范覆盖矩阵。

## v1.1
新增民法典专项层。

## v1.2
新增民事诉讼、强制执行、企业破产第二基础法律层。

## v2.0
升级为全链条法律规范 Skill，新增公司、仲裁、刑事、银行保险证券基金期货、信托资管、反洗钱、税务会计、市场竞争、消费者保护、数据个人信息、行政监管、国资、外汇涉外、公安反诈、不动产、劳动、知识产权等法域，并建立开放式衔接规则。

同时纳入截至2026年的重要换法节点：新公司法、新反洗钱法、民营经济促进法、新反不正当竞争法、增值税法、修改后的网络安全法、新仲裁法及2025年执行异议之诉司法解释。

本包是检索/分析 Skill 规范，不是全部历史规范文件的离线镜像。实际使用必须动态查询官方公开来源并核验效力。
