# 使用示例

## 1. 文件原文与效力

**用户：** 查财金〔2017〕90号文目前是否有效，并找出后续修改、引用和陕西落地文件。

**执行：**
- 读取 `references/SOURCE_MATRIX.md`；
- 按财政部 → 国家级官方法规库 → 陕西财政/金融/法院等官方来源检索；
- 使用 `references/VALIDATION_CHECKLIST.md` 核验效力；
- 区分全国规则与陕西地方落地文件。

## 2. 不良贷款核销

**用户：** 分析陕西农信向农商行转型过程中历史小额不良贷款的核销条件。

**执行：**
- 读取 `references/LEGAL_COVERAGE_MATRIX.md`；
- 同时扫描金融监管、财政会计、税务、民法典债权、执行/破产、地方高院及地方金融规则；
- 区分会计核销/监管出表与实体债权消灭。

## 3. SPV 与执行

**用户：** SPV受让200笔已仲裁债权，能否在所在地中院以一个执行号批量强制执行？

**执行：**
- 先核验每笔执行依据、执行管辖、受让后的申请执行人资格；
- 检查执行立案/案号/合并执行规范；
- 不得因债权包商业上不可拆分直接推定一个执行号合法；
- 联动债权转让、仲裁法、民诉执行、变更当事人、异议救济和破产规则。

## 4. 历史监管文件

**用户：** 找原银监会关于不良资产批量转让的历史文件，现在还能不能用？

**执行：**
- 走“银监会 → 银保监会 → 金融监管总局”的机构映射；
- 查后续修改、废止和清理文件；
- 不得仅因银监会已撤销就认定文件失效。

## 5. 草案防误用

**用户：** 金融稳定法对当前业务有什么要求？

**执行：**
- 先核验截至检索日是否已正式通过并施行；
- 若仍属草案/立法动态，只能作为立法观察，不得作为现行义务依据。
