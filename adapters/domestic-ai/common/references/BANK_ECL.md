# 银行预期信用损失（ECL）专题

版本2.6.0；专题核验日2026-10-27。原文身份及所引条款置信度高；后续修订废止未穷尽核验，持续效力置信度中。本文件为分析指引，不是法规正文。原始资料、文字提取件、链接和哈希见[BANK_SOURCE_INDEX.md](BANK_SOURCE_INDEX.md)第1—5项；核销另读[BANK_WRITEOFF.md](BANK_WRITEOFF.md)。

## 1. 依据与范围

- 《企业会计准则第22号——金融工具确认和计量》（财会〔2017〕7号，下称准则22）：第39—43条涉及利息、信用减值、合同修改和直接减记；第46—63条规范ECL。
- 《商业银行预期信用损失法实施管理办法》（银保监规〔2022〕10号，下称银行办法）：第4条敞口范围，第22条阶段划分，第23—30条模型与更新，第31—33条披露、报告。通知落款2022-05-13，第40条规定自公布之日起施行，第41条的延期申请最迟实施日为2023-01-01。原文18页PDF已保存。
- 《企业会计准则第37号——金融工具列报》（财会〔2017〕14号）：第81—87条涉及信用风险、参数、准备变动、担保与敞口披露。
- 《商业银行金融资产风险分类办法》（银保监会、人民银行令2023年第1号）：2023-07-01施行，五级分类与ECL阶段各有判断规则。
- 财政部2023-07-17信用增级实施问答：属于合同组成部分的担保等回收可纳入，已单独确认的相关现金流量不能重复计入。

适用境内商业银行，包括农商行；村镇银行等依银行办法第38条参照适用。准则2017年修订按通知分批实施，不能把网页日期当成所有银行的统一首次施行日。

准则22第46条主要覆盖摊余成本金融资产、债务工具类FVOCI资产、租赁应收款、合同资产及符合条件的贷款承诺、财务担保。FVTPL资产不另按该条计提ECL准备，但银行办法第4条要求对承担信用风险的其他公允价值金融资产进行ECL评估，以判断公允价值计量合理性；不能把评估要求变成重复计提。

FVOCI债务工具的减值损益计入当期损益，准备在其他综合收益确认，不直接减少资产负债表列示价值（准则22第49条）。表外承诺须估计未来提用，不得直接把全部授信额度当作EAD。

## 2. 三阶段及SICR

下表用于非POCI、采用一般减值模型的金融资产；简化模型和表外项目另行判断。

|阶段|风险状态|准备|利息收入基础|
|---|---|---|---|
|第一阶段|相对初始确认风险未显著增加|未来12个月ECL；存续期更短的取剩余期|账面余额×实际利率|
|第二阶段|风险显著增加但尚未信用减值|全存续期ECL|账面余额×实际利率|
|第三阶段|已发生信用减值|全存续期ECL|扣减准备后的摊余成本×实际利率|

依据为准则22第39—40、48、52—59条及银行办法第22条。12个月ECL是未来12个月内可能违约所造成的全程现金短缺，不是仅未来一年少收的现金。

SICR比较初始与报告日的存续期违约风险，不是比较ECL金额。评估经营现金流、财务恶化、评级、跨行逾期、重组让步和前瞻因素；抵押充足不替代对借款人信用恶化的判断。

银行办法第22条：通常不得只凭逾期天数或用五级分类代替阶段；超过30天逾期至少第二阶段，除非有充分合理信息证明风险未显著增加；超过90天进入第三阶段，除非有充分合理信息证明并未违约。例外须留证，不得直接套用到监管风险分类的独立最低标准。

对公第三阶段上迁第二阶段，至少观察6个月按时还本付息且预期未来正常还款；第三阶段不得直接上迁第一阶段。展期或重组本身不能证明信用改善。未终止确认的合同修改须分别处理修改损益与减值（准则22第42、56条），不能合并掩盖损失。

POCI（购买或源生已发生信用减值的金融资产）单列：使用经信用调整实际利率，仅将初始确认后全存续期ECL累计变动确认为准备，不机械套用普通三阶段初始准备（准则22第39、47、57条）。

## 3. 组合模型、前瞻与管理层叠加

银行办法第23—24条原则上使用PD/LGD模型；确有困难可用损失率法或母行、集团等模型，但仍须验证本行适配性。

```text
ECL = sum_s weight_s * sum_t marginal_PD_s,t * LGD_s,t * EAD_s,t * DF_t
DF_t = (1 + EIR)^(-t)
sum_s weight_s = 1
```

这是常见离散表达式，不是法定唯一算法。marginal_PD是从报告日起该时间段首次违约的无条件概率；条件PD须先乘此前存活概率，累计PD不能逐期相加。第一阶段限制违约事件窗口，回收损失可以延续至窗口之后。明确LGD折现基准，已折现到报告日的LGD不得再次完整折现。

情景及权重须基于合理证据，并与PD/LGD/EAD保持一致。基准、悲观、乐观不是法定固定三种，更不存在法定60/30/10权重。管理层叠加用于暂未被阶段、模型和前瞻参数覆盖的风险，应记录量化依据、审批、重复计量检查和退出条件；长期风险纳入模型，不得倒推目标利润。

## 4. 单笔抵押不良贷款的回收现金流法

对报告日已信用减值、非POCI贷款，准则22第59条第（五）项支持以下计量基础：

```text
PV_s = sum_t expected_net_collection_s,t / (1 + original_EIR)^t
ECL = gross_carrying_amount - sum_s weight_s * PV_s
```

这是同一账面口径的概率加权估计，不免除全行模型治理。若出现异常负值或回收超过合同权利，应复核余额、利息、现金流和重复回收，不用机械截断掩盖问题。

分别测算债务人经营回款、抵押物净回收、有效担保及其他清偿来源。同一资产、同一回款不重复计算，考虑担保代偿后的代位关系。抵押净回收应核对权属、顺位、占用租赁、处置限制、优先债权、适用税费、拍卖及保管费用、分配比例、处置时点与失败情景。扣减限于实际优先扣除或本债权承担的项目，不重复扣费。

无法拍卖应反映在回收概率、金额和时间，不直接推导ECL为0或100%。即使全额收回，延期仍可能产生信用损失（第47条）。一般按原实际利率折现；POCI、浮息和特定修改情形另依准则，不能随意换成当期LPR。信用增级已单独确认的现金流不得再计入。

## 5. 假设算例与敏感性（非真实案件）

假设非POCI第三阶段余额1,000,000元，原实际年利率5%；每个情景仅在所列时点取得一次净回款，之后没有其他回款。

|情景|权重|净回款（元）|距报告日年数|现值（元）|
|---|---:|---:|---:|---:|
|基准|60%|700,000|2|634,920.63|
|悲观|30%|300,000|4|246,810.74|
|乐观|10%|900,000|1|857,142.86|

用未四舍五入现值加权，回收现值540,709.89元，ECL为459,290.11元（45.9290%）。全部回款延迟一年且其他条件不变，ECL为485,038.20元，增加25,748.09元。参数全部是假设，不是任何银行或客户事实；ECL比例不直接决定五级分类或核销资格。

## 6. 治理与底稿

银行办法第21—33条要求：风险分组和阶段标准至少年度重检；前瞻信息及模型参数至少半年度更新，重大变化及时更新；ECL结果至少季度更新；模型投产后表现至少年度评估；至少每3年聘请独立外部第三方全面验证，原则上不得为同期年报审计事务所。法人实施报告原办法要求每年4月30日前报送，现承继机关及报送口径需另核。

留存报告日、账面余额、现有准备、原实际利率、初始与当前风险、阶段和五级分类差异、合同修改、净回收证据、情景及参数版本、叠加、验证、审批和敏感性，确保历史结果可复现。将期初准备、计提/转回、核销、回收及其他变动与总账和披露调节表核对；依准则37第81—87条披露重大假设、信用增级和集中度。

ECL计提、一般准备、监管拨备指标、财务核销、会计终止确认、税前扣除与实体债权消灭必须分别结论；具体核销依据、证据与后续追偿见下一专题。
