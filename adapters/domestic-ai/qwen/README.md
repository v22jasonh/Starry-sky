# 千问 / Qwen 适配版

版本：**2.4.0-qwen.1**

本目录用于将“中国金融官方文件检索、效力分析与合同审核”方法部署到支持智能体角色设定和知识库文件的千问/Qwen 场景。

## 推荐配置

1. 把 `SYSTEM_PROMPT.md` 完整复制到智能体的系统指令、角色设定或等效字段；
2. 将 `references/` 文件上传到知识库；
3. 开启平台可用的联网搜索/网页检索能力时，优先用于现行法规和官方原文核验；
4. 不要让知识库中的旧法规文本覆盖联网核验到的新版本；
5. 对合同审核任务，要求模型优先检索 `CONTRACT_REVIEW_METHODOLOGY.md` 和对应专项文件。

## 建议开场指令

可直接向智能体输入：

- “按金融文件方法检索并核验这个文件的现行效力。”
- “站在受让方立场，按 NPL 专项审核这份协议。”
- “按银行授信专项审核，Critical 和 High 风险必须给出替换条款。”

## 兼容说明

千问产品界面的具体字段名称可能随版本变化。如果无法设置独立系统提示词，可将 `SYSTEM_PROMPT.md` 放入智能体的长期角色说明或首条固定指令，并把参考文件上传到知识库。
