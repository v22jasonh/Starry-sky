# 官方文件核验清单

对拟作为关键依据的文件，至少记录并核验以下字段：

| 字段 | 核验要求 |
|---|---|
| 文件全称 | 与官方正文标题一致 |
| 文号 | 无文号时明确“未见文号”，不得猜测 |
| 发文机关 | 区分主发文与联合发文机关 |
| 成文/印发日期 | 优先正文或正式附件记载 |
| 网站发布日期 | 与成文日期分开记录 |
| 施行日期 | 注意“公布之日起施行”等表述 |
| 失效/废止日期 | 有明确决定时记录 |
| 文件类型 | 法律、行政法规、司法解释、规章、规范性文件等 |
| 效力层级 | 不根据标题名称臆断 |
| 适用地域 | 全国/地方/特定区域 |
| 适用对象 | 银行、保险、证券、企业、个人等 |
| 当前状态 | 未施行/现行有效/已修改/部分失效/已废止/已失效/征求意见 |
| 修改文件 | 列出修改决定及日期 |
| 废止文件 | 列出废止/清理依据 |
| 替代文件 | 有新规替代时列明 |
| 官方原文 | 原发文机关优先 |
| 官方备份 | 官方公报/国家级法规库/联合发文机关转载 |

## 效力判断最低动作

1. 搜索同名文件及文号；
2. 搜索“修改”“废止”“失效”“清理”“现行有效”等后续信息；
3. 检查官方法规库的状态字段；
4. 检查新法/新规是否明确替代或同时废止；
5. 检查上位法变化是否造成实质冲突；
6. 对历史机构文件检查承继机关和机构改革后的清理结果；
7. 关键结论尽量由两个官方来源交叉确认。

## 证据不足时的表达

- 已核验原文，但未找到官方效力状态：写“原文已核验，现行效力仍需结合后续清理文件确认”。
- 仅有官方转载：写“目前仅核验到官方转载，尚未找到原发文页面”。
- 仅有非官方线索：不得把文件作为关键依据，应继续检索或明确“未能核验”。
