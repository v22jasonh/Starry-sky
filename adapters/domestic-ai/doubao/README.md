# 豆包 / Doubao 适配版

版本：**2.4.0-doubao.1**

本目录用于将“中国金融官方文件检索、效力分析与合同审核”方法部署到支持智能体提示词和知识库/文件能力的豆包相关场景。

## 推荐配置

1. 将 `SYSTEM_PROMPT.md` 放入智能体的人设、系统提示词、角色指令或等效位置；
2. 将 `references/` 上传到知识库或智能体文件区；
3. 如可配置联网搜索，要求对现行法律、监管文件、司法解释和地方规则优先核验官方来源；
4. 对较长合同先定位条款，再使用方法论和专项清单逐项审核；
5. 对重大结论输出“事实 / 依据 / 判断 / 待确认事项 / 置信度”。

## 建议开场指令

- “用金融文件审核框架判断这份监管文件是否仍有效。”
- “按 SPV/资产处置专项审核这份协议，先重建资金流和资产流。”
- “只列 Critical 和 High 风险，并给出可直接替换的条款。”

## 兼容说明

豆包及其智能体产品的具体配置入口可能随版本变化。本适配版不依赖专有目录协议，核心是把 `SYSTEM_PROMPT.md` 作为长期指令，把 `references/` 作为知识库。
