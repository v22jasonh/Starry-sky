# 智谱 / Zhipu 适配版

版本：**2.4.0-zhipu.1**

本目录用于将“中国金融官方文件检索、效力分析与合同审核”方法部署到支持智能体系统提示词和知识库/文件上传的智谱相关场景。

## 推荐配置

1. 将 `SYSTEM_PROMPT.md` 作为智能体系统指令或长期角色设定；
2. 将 `references/` 文件导入知识库；
3. 如平台支持联网搜索或网页工具，对现行规范必须优先查官方来源并核验效力；
4. 对历史案件先建立法律事实时间轴，避免机械套用现行法；
5. 对合同审核优先加载通用方法论，再按授信、NPL、SPV类型加载专项模块。

## 建议开场指令

- “查找并核验这份文件的官方原文、文号和现行效力。”
- “按 NPL 转让专项，从受让方立场审核并输出红线条款。”
- “把实体法、执行程序、破产和核销规则分层分析。”

## 兼容说明

智谱不同产品的智能体/知识库配置名称可能变化。本目录采用通用提示词 + 知识库结构，不依赖单一产品的私有格式。
