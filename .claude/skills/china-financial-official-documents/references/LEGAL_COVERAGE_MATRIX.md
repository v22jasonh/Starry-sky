# 金融业务全链条法律规范覆盖矩阵

> 本矩阵规定最低检索覆盖面，不是封闭清单。事实触发清单外法律关系时，必须继续扩展检索。

## 一、基础法层

1. 宪法、立法法、法律解释、修改/废止决定；
2. 民法典及其时间效力、总则、物权、担保、合同编等司法解释；
3. 历史法律事实对应的原民法通则、民法总则、合同法、物权法、担保法等旧法及旧司法解释；
4. 公司法、合伙企业、企业登记、股东责任；
5. 企业破产法及破产法司法解释（一）（二）（三）。

## 二、争议解决与强制执行层

至少扫描：

- 民事诉讼法及民诉法司法解释；
- 证据、管辖、送达、财产保全；
- 仲裁法及仲裁相关司法解释；
- 公证债权文书；
- 执行立案、结案、执行管辖；
- 财产调查、网络查控；
- 查封、扣押、冻结、续封续冻、轮候查封；
- 司法评估、拍卖、变卖、以物抵债；
- 执行异议、复议、案外人异议及执行异议之诉；
- 变更/追加申请执行人、被执行人；
- 终结本次执行与恢复执行；
- 执行和解、执行回转；
- 参与分配、案款分配；
- 失信、限消、罚款、拘留、拒执犯罪衔接；
- 执行转破产。

## 三、银行与非银金融监管

至少扫描：

- 商业银行、政策性银行、农村信用社/农商行、城商行；
- 消费金融、汽车金融、小额贷款；
- 金融资产管理公司、地方AMC；
- 融资担保、典当、商业保理、融资租赁等地方金融组织；
- 贷款分类、授信、风险管理、不良资产认定与处置；
- 呆账核销、核销出表、批量转让、不良资产转让；
- 金融消费者保护；
- 征信、支付结算、账户管理。

历史监管文件要沿金融监管总局及原银保监会、银监会、保监会回溯。

## 四、证券、保险、基金、期货与资管

至少扫描：

- 证券法、证券发行与交易；
- 基金法及基金监管；
- 期货和衍生品法；
- 债券、资产证券化、交易所/银行间市场规则；
- 保险法及保险监管；
- 信托、银行理财、资管产品；
- 行业协会和交易基础设施自律规则，并明确其并非国家行政规章。

## 五、金融合同与担保工具

至少扫描：

- 借款、保证、抵押、质押、留置；
- 债权转让、债务加入、代位权、撤销权、抵销；
- 保理、融资租赁、所有权保留；
- 票据；
- 应收账款、动产和权利担保登记；
- 共同债务、连带责任、第三人代偿。

## 六、反洗钱、刑事与公安衔接

至少扫描：

- 反洗钱法、客户尽职调查、受益所有人、可疑交易；
- 反恐怖融资；
- 非法吸收公众存款、集资诈骗、贷款诈骗、骗取贷款；
- 洗钱、掩饰隐瞒犯罪所得；
- 拒不执行判决裁定；
- 帮信、妨害信用卡管理等可能与账户/资金链相关罪名；
- 公安反诈、涉诈账户冻结、资金返还和刑民交叉程序。

## 七、财政、会计、税务与审计

至少扫描：

- 金融企业财务制度；
- 金融企业呆账核销、资产损失；
- 会计准则、减值、终止确认；
- 企业所得税资产损失税前扣除；
- 增值税及金融服务税收规则；
- 不良资产转让、债权转让、处置收益相关税务；
- 审计和国有金融资本管理规则。

必须区分：会计核销、监管出表、税务损失确认、实体债权消灭。

## 八、市场监管与消费者保护

至少扫描：

- 市场主体登记；
- 反垄断、反不正当竞争；
- 价格、广告；
- 消费者权益保护；
- 格式条款、公平交易；
- 企业信用信息公示。

## 九、数据、个人信息、网络安全与征信

至少扫描：

- 网络安全法；
- 数据安全法；
- 个人信息保护法；
- 征信业管理；
- 金融数据跨境、数据出境、网络安全等级保护；
- 电子签名、电子合同、电子证据；
- 催收、风控、画像、共享数据中的个人信息处理合法性。

## 十、行政监管与救济

至少扫描：

- 行政许可法；
- 行政处罚法；
- 行政强制法；
- 行政复议法；
- 行政诉讼法；
- 国家赔偿法；
- 监管检查、责令整改、市场禁入、资格处罚等专项规则。

## 十一、国资、跨境与涉外

至少扫描：

- 企业国有资产法、国有金融资本管理；
- 国资交易、评估、转让；
- 外汇管理；
- 外商投资；
- 境外融资、跨境担保、跨境债权；
- 涉外民事关系法律适用；
- 国际司法协助、外国判决/仲裁裁决承认执行；
- 制裁、出口管制、反外国制裁等在具体跨境交易中的适用。

## 十二、不动产、劳动、知识产权及其他资产

根据资产性质扫描：

- 土地、不动产登记、房地产、建设工程；
- 劳动、社保、职工债权；
- 专利、商标、著作权及知识产权质押融资；
- 矿业权、特许经营权等特殊财产权；
- 政府采购、招投标、政府应付款；
- 中小企业账款支付、民营经济相关规则。

## 十三、地方规则

涉及具体省市时，继续检索：

- 地方性法规、政府规章；
- 地方金融管理部门文件；
- 省级财政、税务、市场监管配套规则；
- 省高院、金融法院的审判/执行指引和正式司法文件；
- 地方国资、不动产、公安等部门规则。

地方规则不得突破上位法授权，且必须标注地域适用范围。

## 十四、强制衔接链

涉及金融债权处置时默认按以下链条核验：

**主体资格 → 交易效力 → 债权债务 → 担保与优先权 → 金融监管 → 财政/会计 → 税务 → 公司责任 → 仲裁/诉讼 → 保全 → 强制执行 → 执行异议/追加 → 破产 → 刑事 → 数据/个人信息 → 行政监管 → 地方规则。**

该链条是最低检查路径，不是检索上限。
